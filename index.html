U1

Document Chatbot — Hybrid RAG System

PythonLangChainFastAPIChromaDBReact
  • Built a full-stack retrieval-augmented chatbot answering questions over uploaded PDF, Word, PowerPoint, and Excel documents, with per-session isolated vector stores for multi-user safety.
  • Designed a hybrid retrieval pipeline combining dense vector search (ChromaDB, HuggingFace embeddings) with BM25 keyword search, merged by document identity.
  • Added a cross-encoder reranking stage (BAAI/bge-reranker-base) with score thresholds, returning an explicit "not enough information" response instead of hallucinating.
  • Engineered a context-restricted Gemini prompt that flags conflicting information across sources rather than silently resolving it, with a source list appended after generation.
